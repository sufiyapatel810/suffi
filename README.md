# Sufiya Patel — Portfolio

Built with React, TypeScript, Vite, Tailwind CSS and Motion.

## Run locally

```
npm install
npm run dev
```

Open http://localhost:3000

## Make it yours

- **Text, links, projects, skills:** edit `src/data.ts`
- **Portrait:** put a transparent-background PNG at `public/portrait.png`
- **Project screenshots:** put them in `public/projects/` (names are set in `src/data.ts`)
- **Resume:** put a PDF at `public/resume.pdf`

## Deploy

Push to GitHub, then import the repo on Vercel (framework: Vite). Build command `npm run build`, output `dist`.
